인스타 웹(브라우저 패널)으로 카드 게시할 때, 자르기 단계에서 '자르기 선택' 메뉴의 **4:5를 직접 클릭**하고 미리보기 비율(≈0.8)을 확인한 뒤 넘어간다.

**Why:** 2026-10-01 DAY 04를 화면상 세로로 보인다고 4:5로 가정하고 올렸다가 비율이 틀려 운영자가 삭제 후 재게시함.

**How to apply:** 사진 선택은 운영자가 직접 함(파일 창). 이후 JS로 dialog 의 svg[aria-label="자르기 선택"] → '4:5' 버튼 클릭, 미리보기 img 278x348 같은 0.8 비율 확인 → 다음 → 다음 → 9개 점 확인 → 캡션은 아래 '캡션' 방식으로. 자르기·다음 버튼은 JS click 으로 됨(패널이 좁아 좌표 클릭이 빗나감), 캡션 저장 버튼만 실제 클릭. [[ontology-insta-channel]]

**캡션 (2026-10-01 두 번 실패):** JS paste 이벤트로 넣은 캡션은 글자 수 표시만 바뀌고 저장 안 됨. 실제 키 입력(computer type, 줄바꿈은 shift+Enter 키)을 해도 '공유하기/완료'를 JS .click() 으로 누르면 캡션이 빠짐. **완료 버튼은 computer left_click(실제 클릭)** 으로 눌러야 저장됨. 공유 후엔 게시물 페이지 meta og:description 에 캡션이 있는지 반드시 확인. 캡션이 빠졌으면 삭제하지 말고 '옵션 더 보기 → 수정'으로 넣으면 됨. 긴 캡션은 나눠서 저장해도 됨.

**2026-10-12 크롬 경로 (DAY 13 성공):** 사용자가 내장 패널 대신 평소 크롬 선호 → Claude in Chrome 확장 설치·로그인 후 진행. 인스타 로그인은 사용자가 직접. 만들기 → 게시물 → read_page 로 dialog 안 `button type="file"` ref 찾아 file_upload 로 **직접 업로드 가능**(사용자 파일 선택 불필요). 단 한 번에 10MB 제한 → PNG 9장(약 13MB)은 System.Drawing 으로 JPG 품질 95(장당 ~300KB)로 scratchpad 에 변환 후 업로드. 4:5 는 find 로 버튼 찾아 클릭, 다음 2번은 JS click 으로 됨. 캡션은 computer type + shift+Enter 로 입력(중간에 CDP 타임아웃 나도 실제론 입력됐을 수 있으니 contenteditable innerText 로 확인 후 이어서), 공유하기는 find ref 로 실제 클릭 → 한 번에 저장됨.
