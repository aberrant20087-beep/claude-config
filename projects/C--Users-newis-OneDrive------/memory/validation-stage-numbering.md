회사(바이오써포트) 프로젝트 폴더의 단계 번호. **표준 패키지와 실제 프로젝트가 다르다.**
실제 프로젝트를 따라야 한다.

| 번호 | 실제 프로젝트 (기준) | 표준 패키지 (옛 버전) |
|---|---|---|
| 00 | 개념설계 | 개념설계 |
| 01 | 밸리데이션 시스템 기획 (VMP) | 〃 |
| 02 | 컴퓨터시스템 밸리데이션 기획 (CSV) | 〃 |
| 03 | 품질위험경영 시스템 기획 | 〃 |
| 04 | **품질위험평가(RA)** | 〃 |
| 05 | **사용자요구규격서(URS)** | 〃 |
| 06 | **적격성평가 계획서(QP)** ← 표준엔 없음 | 설계적격성평가(DQ) |
| 07 | 설계적격성평가(DQ) | 설치적격성평가(IQ) |
| 08 | 설치적격성평가(IQ) | 운전적격성평가(OQ) |
| 09 | 운전적격성평가(OQ) | 성능적격성평가(PQ) |
| 10 | 성능적격성평가(PQ) | 밸리데이션 |
| 11 | 밸리데이션 | 공급자 문서 관리 |
| 12 | 공급자 문서 관리 | 프로젝트 관리 |
| 13~17 | 프로젝트관리 · 데이터관리 · 현장사진 · 기타 · 계약관리 | (한 칸씩 앞) |

**RA(04)가 URS(05)보다 앞이다.** FAT·SAT 는 독립 단계가 아니라 `공급자 문서 관리` 하위에 있다.

## 단계 안의 구조

`DQP/DQR`(계획서/결과서) → 설비 카테고리(01_HVAC ~ 08_생산장비) → 개별 장비.
문서 세트는 `00 실시계획서` → `01·02·03… 시험 기록양식` → `00 결과보고서` 순.

- **DQ 는 시험이 전 설비 공통 3종**: 준비상태 확인 / 공급자 확인 URS 및 URS Deviation 문서화 확인 /
  설계의 URS 요구사항에 대한 적격성 확인.
- **IQ·OQ 는 설비마다 시험 항목이 다르다.** 같은 `02` 번호에 '재질 확인'과 '제어판 기능 확인'이
  따로 붙는다. 하나의 양식으로 묶을 수 없고 설비 유형별 세트로 봐야 한다.

**Why:** 내가 이 번호를 두 번 틀리게 제안했다(처음엔 임의 번호, 다음엔 표준 패키지).
실제 프로젝트 폴더를 직접 확인하지 않으면 또 틀린다.

**How to apply:** 단계 관련 작업 전에 `G:\공유 드라이브\...\프로젝트_진행 중\<프로젝트>` 의
폴더 이름을 먼저 읽어 확인할 것. 표준 패키지 폴더는 신뢰하지 말 것.
