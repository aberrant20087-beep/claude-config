`G:\공유 드라이브` 는 회사 공용이라 **지금 이 순간에도 동료가 열어보거나 편집 중일 수 있다.**
사용자가 명시적으로 요구했다: "공유드라이브에서 직접 내용변경하는 일은 절대로 일어나지 않았으면 좋겠어."

- **쓰기 · 이동 · 이름변경 · 삭제 금지.** 사용자가 요청하더라도 한 번 더 확인받는다.
- 읽기(열람 · 필요한 것만 복사해 오기)만 한다.
- **하위 폴더를 통째로 복사해 오지 않는다.** 필요한 것만 고른다.
  실제로 양식 347개 파일이 접미사만 다른 96종이었다 — 골라오면 1/3 이하로 준다.
- 결과물은 `G:\내 드라이브` 나 `PROJECT_SEOL` 안에만 만든다. 여기는 자유롭게 바꿔도 된다.

**Why:** 남의 작업을 덮어쓰면 되돌릴 수 없고, 회사 문서라 파장이 크다.
용량 낭비보다 "원본이 어디인지 헷갈리는 것"이 더 큰 문제라고 사용자가 지적했다.

**How to apply:** `sync.ps1` 은 `G:\내 드라이브` 만 본다 — 이 범위를 넓히지 말 것.
공유 드라이브를 다루는 스크립트를 새로 만들 때는 읽기 전용 경로만 쓰고,
`Move-Item`/`Remove-Item`/`Copy-Item -Destination` 의 대상이 공유 드라이브가 되지 않는지 확인한다.
