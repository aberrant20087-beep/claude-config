사용자에게 보이는 답변·요약·질문은 항상 한국어로 쓴다. 코드 주석·커밋 메시지도 지금처럼 한국어를 유지한다.

**Why:** 2026-09-26 에 결과 보고를 영어로 했더니 사용자가 "한글로 말해"라고 바로잡았다. 사용자는 한국어로 일하는 GMP 밸리데이션 엔지니어다 ([[user-gmp-validation-engineer]]).

**How to apply:** 출력 스타일이 바뀌거나(간결 모드 등) 도구 결과가 영어여도, 사용자에게 쓰는 문장은 한국어로 쓴다. 파일 경로·명령어·고유명사만 원문 그대로 둔다.
