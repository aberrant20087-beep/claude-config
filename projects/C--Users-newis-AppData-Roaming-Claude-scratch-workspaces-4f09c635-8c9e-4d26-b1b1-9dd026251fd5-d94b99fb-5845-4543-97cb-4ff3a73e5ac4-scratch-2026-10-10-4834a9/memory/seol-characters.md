SEOL 프로젝트 캐릭터 4명 (영문 표기 Seori / Poi / Joy / Yeoni). SEOL = Sense(설이) · Embrace(포이) · Organize(조이) · Link(연이).

- 공통: 측면 상반신, 리본 + 둥근 헤드폰 + 흰 카라, 갈색 선화 베이스.
- 설이: 단발, 아이스크림, 테마색 토파즈(#F2A23A, 오렌지~노랑 사이).
- 포이: 앳된 모습, 긴 머리, 병아리, 노랑(#F7CF3D).
- 조이: 긴 생머리, 펜, 진한 붉은색(#9E1F33).
- 연이: 단발 + 끝만 살짝 휜 앞머리, 안경, 네잎클로버(link 컨셉), 남색(#1E2A5E).
- 2D 컬러(2026-10-10): 머리색은 확실히 밝게, 4명 각자 조금씩 다른 톤. 팔/소매는 흰색, 테마색은 몸판에만.
- 3D: 테마색 원피스(흰 블라우스 위) + 테마색 단화 + 흰 양말. 치마는 풍성하지 않게 거의 일자로.
- 3D 비율: 설이 기준 키·얼굴 크기 통일, 포이(막내)만 살짝 작게. 다리는 얇게.
- 단화는 끈/스트랩 없는 플랫. 색감은 선명하게(바랜 느낌 X), 배경은 따뜻한 흰색.
- 피부는 2D처럼 밝은 톤. 홍조는 포이만 살짝, 나머지 3명은 없음.
- 연이 머리는 따뜻한 라떼 베이지(회색 X). 연이 남색은 진하게(바랜 느낌 X).
- 소매는 펑퍼짐하지 않게 슬림. 눈은 4명 모두 따뜻한 갈색(검정 X).
- 헤드셋: 밴드·이어컵 바깥면은 테마색(원색), 귀에 닿는 안쪽 쿠션만 흰색, 글씨/로고/C마크 없음.
- 표정: "환하게/더 웃게" = 눈썹만 살짝 올리는 것. 눈 감기(^^)나 표정 크게 바꾸기 X, 눈은 항상 뜬 상태.
- 원피스는 테마색 데님 소재, 치마 밑단에 살짝 도톰한 흰색 밴드(전신일 때).

- 홈페이지 연동: 캐릭터를 바꾸면 바탕화면 `SEOL/characters/3d-*.webp`(투명, 높이 640, 공통 세로 기준) + `cutout/*.png`를 교체하고 이전본은 `_backup_YYYYMMDD/`에 백업. 그 뒤 반드시 SEOL 페이지 세션(제목 "SEOL 페이지 작업 시작", local_1f994ac5-…)에 send_message로 알리고 재게시 요청. 역할 규칙은 `SEOL/CLAUDE.md`.

- 공식 사이트: Cloudflare Pages 프로젝트 `seol` → https://seol-dqx.pages.dev (2026-10-11 첫 배포). 배포 절차는 `SEOL/CLAUDE.md` 참고. 캐릭터 바꾸면 build_site.py → 재배포까지.

- 2026-10-17 방침 변경: 캐릭터별 이미지 작업은 각 캐릭터 세션이 직접 함(설이=SEORI, 포이=POI, 조이=JOI, 연이=YEONI 세션; SEOL/CLAUDE.md에도 반영됨). 캐릭터 이미지 변경이 필요하면 해당 세션에 요청. 이 세션은 개별 캐릭터 이미지(characters/3d-*.webp, cutout)를 요청 없이 덮어쓰지 않는다. 이 세션 현재 담당: 예고편(트레일러) 제작. 작업 시작·종료 시 SEOL/STATUS.json 갱신 + tools/status_md.py.

**Why:** 사용자가 2026-10-10 세션에서 확정. 설이=토파즈/포이=노랑 배정은 SEOL 페이지 세션에서의 말과 반대였는데 사용자가 이 배정으로 확인함.
