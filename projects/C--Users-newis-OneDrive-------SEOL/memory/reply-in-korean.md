사용자에게 보이는 글은 전부 한국어로 쓴다. 작업 중간에 짧게 알리는 진행 상황("~하는 중이에요")과 명령 설명, 작업 목록, 요약, 질문 버튼까지 포함한다. 영어는 사용자가 특정 단어나 문장을 영어로 원할 때만 쓴다(예: 카드에 넣을 영어 문구, 고유명사).

**Why:** 2026-10-17 영어로 답하자 "한글로해 한글"이라고 했다. 그 뒤에도 진행 알림을 영어로 쓰자 "모든 작업 한글로 진행도 알려줘, 영어는 특정 단어나 문장을 요구하는 거 아니면 쓰지 마"라고 다시 바로잡았다.
**How to apply:** 진행 알림 한 줄도 한국어로 쓴다. 이미지·영상 생성 프롬프트처럼 사용자가 읽지 않는 내부 입력은 영어로 써도 된다.
