점검 세션이 찾은 문제는 총괄로 보고하고, 방법이 하나인 것은 담당 세션이 승인 없이 바로 고쳐 배포한다. 고치는 방법이 여러 가지인 경우에만 얼이 승인한다. (2026-11-07 얼 지시, 고객 점검 [[seori-final-goals]] 이후)

**Why:** 얼은 하나하나 승인하는 데 시간을 쓰고 싶어 하지 않는다.

**How to apply:** 총괄은 보고를 받으면 문제를 '방법 하나'와 '방법 여럿'으로 나눠, 앞의 것은 담당 세션에 바로 수정 요청을 보내고 뒤의 것만 선택지로 묶어 얼에게 묻는다. CLAUDE.md의 규칙(출처 없는 수치 금지 등)이 답을 정해 주면 방법 하나로 본다.
