얼(2026-11-08): "크롬으로 하지말고 엣지로 해."

**Why:** 얼은 로컬 확인을 Edge에서 한다.
**How to apply:** 얼에게 로컬 화면을 열어 줄 때는 PowerShell `Start-Process msedge "<url>"`로 연다. Claude in Chrome으로 열지 않는다. 내 검사용 화면은 앱 안 브라우저 창을 써도 된다.
